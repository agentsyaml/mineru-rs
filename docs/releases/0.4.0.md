# MinerU Rust 0.4.0

## Highlights

- Added native CSV and TSV parsing and rendering support.
- Added model listing, download, and integrity verification commands.
- Added optional RAW-layout local inference with `local-inference`; ONNX Runtime must be supplied by the user.
- Hardened cancellation and request-body admission, and fixed certificate handling.
- Updated Tokio to 1.53.3, rustls-webpki to 0.103.16, and webpki-root-certs to 1.0.10 to address security advisories.

## Compatibility

The pinned upstream references are MinerU 4.0.12, DocVortex 0.6.0, and MinerU
Utils 2.0.7. Compatibility checks are model-free smoke checks, not a claim of
full Rust PDF/OCR parity. Older VLM inputs remain supported by default.

Crates.io publication remains disabled under the repository's current release
policy. See [the release guide](../releasing.md) before preparing artifacts.
